# SYNQ — учиться вместе, расти вместе

SYNQ — образовательное приложение для студентов, которое объединяет совместную учёбу, взаимопомощь и геймификацию.

## Цель проекта

Повысить вовлечённость в учёбу и упростить общение между студентами. Концепция может адаптироваться к другим колледжам и учебным группам.

## Функциональность демонстрации

- Пульс понимания учебных тем.
- Вопросы, взаимопомощь, задания и расписание.
- Ежедневные миссии, XP, уровни, достижения и рейтинг.
- Учебные мини-квизы и таймер концентрации.
- Адаптивный интерфейс для смартфонов и компьютеров.

## Запуск

В этом репозитории опубликована оригинальная интерактивная браузерная демонстрация в папке [demo](demo/).

Скачайте репозиторий (Code → Download ZIP), распакуйте и откройте `demo/index.html` в браузере. Для проверки PWA можно запустить локальный сервер:

```bash
cd demo
python -m http.server 8000
```

Откройте http://localhost:8000. Данные демонстрации хранятся локально в браузере; это не многопользовательская серверная версия.

## Статус

Конкурсный прототип. Отдельная full-stack сборка на FastAPI и SQLite существует, но пока не добавлена в этот репозиторий. Демонстрационные данные вымышленные. Для внедрения в колледже требуются проверка безопасности, модерация, защита персональных данных и серверная инфраструктура.

## Проверка демонстрации

1. Откройте главную страницу и переключите разделы.
2. Отметьте понимание темы в Пульсе.
3. Создайте вопрос или проверьте сценарий взаимопомощи.
4. Выполните доступную миссию или мини-квиз.
5. Перезагрузите страницу и проверьте сохранение локального прогресса.

Проект разработан для образовательной среды колледжей.
